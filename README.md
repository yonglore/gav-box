# Гав Бокс

[Единый план проекта: исследование спроса, наборы, закупки и запуск на маркетплейсе](gav-box-overview.md).

Москва · бюджет проверки идеи 10 000 ₽ · учебный MVP к концу октября 2026 года.

Актуальная стратегия: разовые наборы на одном маркетплейсе, подписка — возможное развитие. Все материалы для команды, включая текст одного слайда для майнора, находятся в основном файле обычным регистром. Текущая стадия — идея и подготовка; продавец ещё не оформлен.

Отдельные исследовательские документы ранее убраны из текущей версии; прежние материалы сохранены в истории Git. Калькулятор в `outputs` остаётся техническим черновиком: его параметры не утверждены для запуска на маркетплейсе. Проектные правила честной оценки — в [AGENTS.md](AGENTS.md); это инструкции проекта, а не установленный плагин.
