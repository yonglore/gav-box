## Приложенные материалы пользователя

Два скриншота BarkBox и [исходный файл](../gav-box-overview.md), исходный коммит `dc0a611e545966b540f84e5f20474ce5003d55a7`. Это исходная гипотеза команды, не независимые доказательства. Тезис о маркетинге проверен по раскрытию BARK; уникальность опровергается существованием аналогов; оценка регуляторных рисков пересмотрена. Фраза исходного файла «без ссылок на зарубежные аналоги» не отменяет прямой запрос пользователя анализировать BarkBox.

## Что не удалось или ещё не сделано

- Первичная страница тарифов [Ozon](https://seller-edu.ozon.ru/docs/commissions-tariffs/legal-information/full-actual-commissions.html) вернула ошибку перенаправления. Действующие ставки конкретного набора не установлены. Сторонние противоречивые таблицы в модель как факты не перенесены.
- Отдельная карточка COSMODOG «Спутник» вернула 404. Этот товар не использован как подтверждённое текущее предложение.
- Не снята полная выборка сопоставимых карточек Ozon/WB и их отзывов. Нужно зафиксировать 10–15 наборов/корзин: дата, продавец, состав, веса, полная цена, доставка, наличие, претензии. Не делать вывод о продажах только по числу отзывов.
- Не установлены точный объём московской ниши, реальные оптовые цены, минимальные партии, тарифы доставки и стоимость платящего клиента.
- Не проведены интервью, контрольные покупки, тесты предметов, правовая экспертиза SKU, поиск товарных знаков и переговоры с партнёрами.
- Условия обработки персональных данных и рекламных размещений перечислены как задачи подготовки; полноценного правового аудита конкретной формы и кампании пока нет.
- Не получены дедлайн, бюджет и требования преподавателя. Документы не гарантируют соответствие пока неизвестному заданию.

## Как обновлять

Для каждого нового факта записать URL/документ, дату наблюдения, период данных, точный предмет и ограничение. Для гипотезы — эксперимент, ответственного, бюджет и критерий отказа. Сохранять только обезличенные результаты. Закрытые предложения поставщиков и персональные данные хранить вне публичного репозитория, например в исключённой из Git папке `private/` с отдельно настроенным доступом и резервной копией.
